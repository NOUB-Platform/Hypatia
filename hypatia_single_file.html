💡 طريقة التنفيذ في سوبابيز (Supabase):
  1. افتح مشروعك في Supabase Dashboard.
  2. اضغط على SQL Editor من القائمة الجانبية اليسرى.
  3. اضغط New Query والصق الكود المنسوخ أدناه.
  4. اضغط Run (Ctrl + Enter)، وستنشأ الـ 50 جدولاً مع بياناتها الحقيقية فوراً!
